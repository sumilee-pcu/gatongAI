# 🏫 가정통신문 AI 초안 자동생성 시스템

> **Google Forms + Google Sheets + n8n + Gemini AI + Gmail** 을 연결한 교육 자동화 워크플로  
> 교사가 폼을 제출하면 AI가 즉시 가정통신문 초안을 작성하고 이메일로 발송합니다.

---

## 📌 전체 흐름도

```
[교사] 구글 폼 작성
    ↓ (제목 · 학년반 · 이메일 입력)
[Google Sheets] 응답 자동 저장
    ↓ (1분마다 감지)
[n8n] 폼 응답 감지 트리거
    ↓
[Gemini 2.5 Flash] AI 초안 생성
    ↓
[n8n Set 노드] 데이터 정리
    ↓
[Google Sheets] 초안검토 시트에 저장
    ↓
[Gmail] 교사에게 검토 이메일 발송
```

---

## 🛠 사전 준비물

| 항목 | 내용 |
|------|------|
| Google 계정 | Gmail, Google Forms, Google Sheets 사용 |
| n8n Cloud 계정 | [https://n8n.io](https://n8n.io) 무료 플랜 가능 |
| Gemini API 키 | [Google AI Studio](https://aistudio.google.com/app/apikey) 에서 무료 발급 |

## 📋 STEP 1 — 구글 폼 만들기

### 1-1. 구글 폼 생성

1. [Google Forms](https://forms.google.com) 접속 → **새 양식** 클릭
2. 제목 입력: `가정통신문 작성 요청`
3. 설명 입력: `AI가 초안을 자동 생성합니다. 제목과 학년반 정보를 입력해 주세요.`

### 1-2. 질문 3개 추가 (모두 **단답형**)

| 순서 | 질문 제목 | 필드명 | 필수 여부 |
|------|-----------|--------|-----------|
| 1 | 교사 이메일 | `teacherEmail` | ✅ 필수 |
| 2 | 제목 | `제목` | ✅ 필수 |
| 3 | 학년반 | `학년반` | ✅ 필수 |

> ⚠️ **주의**: 첫 번째 질문의 제목을 반드시 영문 `teacherEmail`로 입력하세요.  
> n8n에서 한국어 필드명 처리 시 공백 문제가 발생할 수 있습니다.

---

## 📊 STEP 2 — 구글 시트 연결

### 2-1. 폼과 스프레드시트 연결

1. 구글 폼 상단 **응답** 탭 클릭
2. **스프레드시트에 연결** 아이콘 클릭
3. **새 스프레드시트 만들기** 선택
4. 이름: `가정통신문 요청 응답` → **만들기** 클릭

### 2-2. 초안검토 시트 탭 추가

1. 생성된 스프레드시트 열기
2. 하단 **+** 버튼 클릭 → 새 시트 추가
3. 탭 이름을 더블클릭 → `초안검토` 로 변경

### 2-3. 스프레드시트 ID 확인

브라우저 주소창에서 ID 복사:
```
https://docs.google.com/spreadsheets/d/【여기가 ID】/edit
```

### 3-3. 각 노드 자격증명 연결

#### 노드 1 — 폼 응답 감지 (Google Sheets Trigger)

1. 노드 더블클릭 → **Credential** 항목
2. **Sign in with Google** 클릭
3. 구글 계정 로그인 및 권한 허용
4. **Document**: 드롭다운에서 `가정통신문 요청 응답` 선택
5. **Sheet**: 드롭다운에서 `설문지 응답 시트1` 선택
6. **Trigger On**: `Row Added`

#### 노드 2 — Gemini AI 초안 생성 (HTTP Request)

- 별도 자격증명 불필요 (API 키를 Query Parameter로 전달)
- `YOUR_GEMINI_API_KEY` 부분에 실제 API 키 입력

> 💡 **Gemini API 키 발급 방법**  
> 1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속  
> 2. **API 키 만들기** 클릭  
> 3. 생성된 키 복사 → n8n 노드에 붙여넣기

#### 노드 3 — 초안 정리 (Set 노드)

별도 설정 불필요. 자동으로 아래 필드를 정리합니다:

| 필드명 | 값 |
|--------|----|
| teacherEmail | 폼에서 입력된 교사 이메일 |
| 제목 | 폼에서 입력된 제목 |
| 학년반 | 폼에서 입력된 학년반 |
| 초안내용 | Gemini AI가 생성한 초안 |
| 생성일시 | 현재 날짜/시간 |

#### 노드 4 — 초안 시트 저장 (Google Sheets)

1. 노드 더블클릭 → **Credential** 항목
2. **Sign in with Google** 클릭 → 구글 계정 연결
3. **Document**: 드롭다운에서 `가정통신문 요청 응답` 선택
4. **Sheet**: 드롭다운에서 `초안검토` 선택
5. **Mapping Column Mode**: `Map Automatically`

#### 노드 5 — 검토 요청 이메일 (Gmail)

1. 노드 더블클릭 → **Credential** 항목
2. **Sign in with Google** 클릭 → 구글 계정 연결
3. 나머지 설정은 자동으로 완성되어 있음

---

## 🚀 STEP 4 — 워크플로 활성화

1. 우측 상단 **Publish** 버튼 클릭
2. **Publish** 확인 클릭
3. 상태가 `Published` ● 로 변경되면 완료

---

## 🧪 STEP 5 — 테스트

1. 구글 폼 URL로 접속
2. 아래 정보 입력:
   - **teacherEmail**: 본인 이메일 주소
   - **제목**: `2학기 현장학습 안내`
   - **학년반**: `3학년 2반`
3. **제출** 클릭
4. **1~2분 후** 입력한 이메일에 AI 초안이 도착하는지 확인

## 🔧 커스터마이즈 방법

### AI 프롬프트 변경

`Gemini AI 초안 생성` 노드의 `contents` 값에서 프롬프트를 수정합니다:

```
당신은 한국 초중학교 교사를 위한 가정통신문 작성 전문가입니다.

제목: [제목]
학년/반: [학년반]

다음 형식으로 가정통신문 초안을 작성해주세요:
1. 인사말
2. 안내 목적
3. 주요 내용
4. 협조 요청사항
5. 문의처
```

### 폴링 주기 변경

`폼 응답 감지` 노드 → **Poll Times** → **Mode** 에서 변경:

| 옵션 | 설명 |
|------|------|
| Every Minute | 1분마다 확인 (기본값) |
| Every Hour | 1시간마다 확인 |
| Custom | 직접 설정 |

## ❓ 자주 묻는 질문

**Q. "Sheet with ID Sheet1 not found" 오류가 납니다.**  
A. `폼 응답 감지` 노드의 Sheet 설정을 드롭다운에서 `설문지 응답 시트1`로 다시 선택하세요.

**Q. 이메일이 안 옵니다.**  
A. Gmail 노드의 자격증명 연결 상태를 확인하세요. `Account connected` 표시가 있어야 합니다.

**Q. Gemini API 호출 오류가 납니다.**  
A. API 키가 올바른지, Google AI Studio에서 Gemini API가 활성화되어 있는지 확인하세요.

**Q. 초안 내용이 초안검토 시트에 안 쌓입니다.**  
A. `초안 시트 저장` 노드에서 Mapping Column Mode가 `Map Automatically`로 설정되어 있는지 확인하세요.
